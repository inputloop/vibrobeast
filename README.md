# vibrobeast

A memory Claude keeps on your own computer, in plain files you can read, with the skills, persona sheets and shared rooms a small free-software shop built around it.

> [!NOTE]
> Version 1.2.59, built 2026-10-16 from source commit `d9d3247`. This is working software used daily by its two makers, not yet reviewed by anyone else. It runs on Claude Desktop (Windows and macOS) and Claude Code. It is not a security boundary: anything Claude can do with your files, it can still do. The parts that reach the network are off until you switch them on.

## What you get

- **Notes that outlast the conversation.** The memory seat keeps what you or Claude choose to write down, as plain files under `~/.mentcached/`. Nothing is ever edited in place: a change is a new generation beside the old one, so you can see what was said before.
- **75 skills.** Written ways of working (careful handbacks, plain-language checks, honest testing) that Claude reads when the task calls for them. They appear in the slash-command menu.
- **Persona sheets.** A persona is a named voice, written down. Claude can say which sheet applies and why, and every change to a sheet is kept.
- **Doors you open yourself** (all off at first): **Tavern**, a common room where people and agents talk and work a shared task board; **Llama Bridge**, which hands small jobs to a model on a machine you choose; **C4**, a work surface for models and drawings; and the **ghostwheel status icon**, which asks hosts you list how they are, and asks you before it looks anything up.
- **A record of where everything goes.** `PRIVACY.md` is rebuilt for every release from claims the build checks against the code, and the build stops if one no longer holds.

## Install

**Claude Desktop, two steps, no typing:**

1. Download [`extension/vibrobeast.mcpb`](extension/vibrobeast.mcpb) and open it. Claude Desktop shows an install page; the settings page that follows is where the doors and their folders live.
2. For the skills in the slash-command menu: in Claude Desktop open **Customize**, then **Plugins**, **Add**, **Upload plugin**, and choose `vibrobeast-skills.plugin`. Ask Claude to run `vibrobeast_setup` and it will put that file in your Downloads folder and say these steps again.

Do not also install the full `vibrobeast` plugin in Claude Desktop: the extension already runs its servers, and two would share one memory.

**Claude Code** (2.1.275 or later, one step):

```
/plugin install vibrobeast --marketplace inputloop/vibrobeast
```

On older versions: `/plugin marketplace add inputloop/vibrobeast`, then `/plugin install vibrobeast@inputloop`.

That plugin carries the servers and the skills together. While this repository is private, adding it needs a GitHub account with access to it.

It needs Python 3.10 or newer. On Windows the extension finds it by itself (the Python launcher, PATH, MSYS2, python.org installs).

## First five minutes

Type these to Claude after installing:

- "What is my seat's mode, and where are my notes kept?" (the tool `seat_mode` answers with the folder and who chose it)
- "Write a note that I prefer plain words in reports." Then, in a new conversation: "What do my notes say about how I like reports?"
- "Which soft skills can you load right now?" (`soft_skills_list`)

## Where your data goes

- **Kept on your computer:** notes, preferences, timings and the persona journal, all under `~/.mentcached/` unless you move them. Every store, what moves it and what is in it is listed in [`PRIVACY.md`](plugins/vibrobeast/PRIVACY.md).
- **Sent by vibrobeast itself:** nothing, until you open a door. With Llama Bridge on, delegated prompts go to the Ollama server you name (this computer by default). With Tavern on, what Claude posts goes to your own Tavern node, which copies it to every member. With the ghostwheel door on, it asks only the hosts you list.
- **Sent by Claude:** what any tool answers becomes part of your conversation with Claude, under Anthropic's terms, not ours.
- **To erase:** delete the folder. Every store is plain text.

## Yours to decide

This is free software, and it is built so the choices stay with you, in practice and not only in the licence.

- **Your words.** Call things what you call them. Tell Claude the word you use and it uses yours; to make it last, `word_register` writes down what a word means to you (one small file per word, never overwritten), and `word_where` finds it again. The project's own terms are explained where they ship (`GRAMMARY.md`), as a glossary, not a rule.
- **Your defaults.** Every default is a preference you can change by asking in plain words (`pref_set`, `pref_list`); the extension's settings page wins over anything set elsewhere.
- **Your keeper.** The keeper is the person an install is for, whose say decides what is kept about people. Put your own name in the settings page's **Keeper** field. (Left empty, this build still names the person it began with; we count that as a bug and are fixing it.)
- **Your byline.** When an agent writes for you, it signs as itself, for you: `persona_byline` gives `Author: NAME (for YOU)`, and the copyright line stays yours. You choose the name, or withhold one. Nothing here signs as you.
- **Your consent.** Doors start closed. The ghostwheel door asks before it looks anything up or trusts a new key; "always" is a separate switch, and only you set it.
- **Your copy.** Everything is plain files you can read, move or delete, under licences that let you run, study, change and share all of it, these words included.

## Permissions

- Each door is a switch on the extension's settings page, or a preference you ask Claude to set in Claude Code. Off means one tool that says so, and nothing sent.
- The ghostwheel door asks before a name lookup or a new host key, shows the key's fingerprint, and refuses a key that does not match the one pinned for that host. "Always" is a separate switch.
- Passwords and the API token are kept in your system's keychain by Claude Desktop and never shown by any tool.

What this does **not** protect: Claude, with these tools, can read and write your notes; a Tavern member sees everything posted there; a host you list sees that you asked.

## Limits

- Two makers, one main test machine (Windows). macOS is supported by the format and less tested.
- Python is not bundled. The extension finds one; if none is 3.10 or newer, it says so in plain words.
- The memory seat is single-writer by design. Do not run two copies of its server against one seat.
- Some parts are explicitly unfinished and say so when called (`skillx` refuses every call and names what it waits on).

## How it came to be

Bryant Frankford spent months showing Corwin Brust how to work with Claude before Corwin knew he wanted to: tell it to keep notes for you, to be sparing with tokens, to write a model of the problem before starting. On late evenings of shared screens the two found they were building tools out of the work itself, and kept going. Corwin, a long-time GNU volunteer, wanted the notes kept the way free software keeps its history: in the open, added to and never rewritten. That became the memory seat. Tavern and Llama Bridge began in Bryant's workshop; the persona sheets and most of the skills grew in Corwin's.

Much of the writing is Claude's, in the voices the gardens have grown: Mentat in Corwin's shop, Alfred in Bryant's. Agent work is signed the same way everywhere here, by the agent, for the person, with the model: `Mentat (for Corwin; claude-opus-5-5)`. The byline says *for* somebody, always; the copyright stays with the person. The name VIBROBEAST is older than any of it: a joke between Corwin and Dee Brust that a group naming call, years later, picked up and kept.

inputloop is the home the two made to share all of it. It is built on the Model Context Protocol and on Claude, by Anthropic.
