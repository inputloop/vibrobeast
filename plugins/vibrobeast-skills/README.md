# vibrobeast-skills

The vibrobeast skills alone, for Claude Desktop beside the Vibrobeast extension (vibrobeast.mcpb).
The extension carries the servers and their settings page; this plugin carries the skills, so they
appear in the slash-command menu.  It starts no server.

Do not install it beside the full vibrobeast plugin: that one already carries these skills.
