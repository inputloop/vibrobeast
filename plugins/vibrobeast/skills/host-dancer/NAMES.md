# NAMES -- the 4x name sheet for the DNS skill

Byline: Mentat (for Corwin, claude-sonnet via subagent).

| name | the case for it |
|---|---|
| host-dancer | The skill is a short choreography with fixed steps (zones, list, plan, show, apply, record) and it is about hosts and zones; says what it does and fits the garden's host names (gw7, gw33). Narrow enough to be DNS-only. |
| external-service-trolley | Names the general idea: a trolley that carries a call to any outside service through C4 and the key door. Right for the umbrella skill later; too wide for DNS alone, and it would claim sway over services we have not built. |
| zone-warden | Stresses the guarding half: bounded domains, no NS/SOA, nothing unnamed deleted. Reads as a gate, not a worker, and may suggest it blocks rather than helps. |
| record-ferry | A ferry carries named records across the water and keeps a log of each crossing, which matches plan-then-apply and the dated record; but it hides that listing and planning are in it. |

**Pick: host-dancer**, for DNS specifically. It is narrow and says it does steps in order. Keep **external-service-trolley** for the
general skill that this one would become a case of once a second kind of service (mail, certificates) is routed the same way.
These names are guesses; his to change.
